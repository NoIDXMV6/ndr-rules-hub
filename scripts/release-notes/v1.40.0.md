## Краш (продакшен): вкладка «DNS списки → Сборка и экспорт»

Падала с `Uncaught TypeError: Cannot read properties of undefined (reading 'toLocaleString')` в `Array.map` — рендер таблицы по источникам читал поля статистики (`droppedDead` появился в v1.37.0, `droppedCategory`/`override` и др. раньше) без защиты, а последняя сборка в БД была сохранена ДО появления полей.

**Фикс:** `lastDomainBuild` нормализует `statsJson` при чтении (`parseDnsStatsJson` терпим к битому JSON; недостающие числовые поля top-уровня и в `perSource` восполняются нулями — старые сборки показываются корректно); плюс защитное чтение (`st.field ?? 0`) в таблице по источникам обеих вкладок сборки (`dns-build-tab.tsx` и `build-tab.tsx`) и для `build.totalDomains`.

## Диагностика 400 /api/sources/<id>/fetch

Эндпоинт и клиент авто-загрузок не имеют (fetchOne — только кнопка «Обновить» на «Правила → Источники»); 400 — задокументированная (openapi 200/400/429) семантика «источник не загрузился», точная причина показывается в UI (сообщение вкладки + красная строка lastError под источником); ошибка консоли «A listener indicated an asynchronous response» — артефакт расширения браузера.

Тесты +2 (551 PASS / 48 файлов): нормализация statsJson старых сборок (полный набор полей, сохранённые числа не искажаются, битый JSON → пустая статистика без падения); tsc чист (вне src — сторонние examples/skills, до правок).
