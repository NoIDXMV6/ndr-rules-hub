Интеграция с RST Cloud (Threat Feed / IoC Lookup / Whois) и токен-только отдача DNS-списка (v1.34.0).

RST Cloud (api.rstcloud.net, коммерческая агрегированная база угроз — 260+ источников с баллом достоверности):
- API-ключ в «Настройки → Токены источников → RST Cloud» (заголовок X-Api-Key, env RST_API_KEY); кнопка «Проверить ключ» — GET /auth/check: валидность, права (entitlements) и квота (used/limit/remaining/period, обычно 1000/день); эндпоинт POST /api/rst/check (только админ).
- Фиды Threat Feed (gzip-CSV с редиректом на подписанное хранилище; конвертер извлекает колонку индикатора, фильтры skipFpAlarm/minScore в extra источника) — четыре источника (выключены по умолчанию, adminOnly, включаются осознанно после ввода ключа):
  • «RST Cloud Threat Feed: IP-адреса» (~110 тыс., чанки по 500, drop ip, SID 1 600 000+) — «Правила → Источники»;
  • «RST Cloud Threat Feed: URL» (~7 тыс. HTTP-правил по host+uri, SID 1 700 000+) — «Правила → Источники»;
  • «RST Cloud Threat Feed: хэши файлов (SHA-256)» (~44 тыс. правил filesha256 — инспекция файлов HTTP-ответов, SID 1 800 000+) — «Правила → Источники»; новая категория hash-list и конвертер convertHashList;
  • «RST Cloud Threat Feed: домены» (~135 тыс. доменов, формат rst-csv, категория malware) — «DNS списки → Источники».
- Проверка индикатора: кнопка «Проверить в RST Cloud» в «DNS списки → Записи» — диалог с IoC Lookup (балл, теги/категории, описание), Noise Control (доброкачественность/false positive) и Whois (статус/регистратор/даты/возраст); эндпоинт POST /api/rst/lookup (только админ); каждая проверка тратит 1 запрос квоты ключа.

Отдача списка доменов — только по токену (v1.34.0):
- Сущность «глобальный ключ отдачи dnsServeToken» удалена: поле «Ключ отдачи списка доменов» и адрес отдачи убраны с вкладки «Сборка и экспорт» (токены управляются ТОЛЬКО в разделе «Аккаунт»); историческая настройка вычищается при старте.
- GET /api/dns/export: БЕЗ ТОКЕНА отдача ЗАПРЕЩЕНА (403 с подсказкой создать токен в «Аккаунт → Токены и доступ»); работают персональный токен со scope «домены»/«оба списка» (?token=… в полном Uri или Authorization) и сессия кабинета (кнопка «Скачать» на вкладках); перебор ключей отсекается прежним rate-лимитом (10/5 мин → 429 на 15 мин).
- Легаси-ключ dnsServeToken (если был задан) доступа больше не даёт — тест подтверждает отказ.
