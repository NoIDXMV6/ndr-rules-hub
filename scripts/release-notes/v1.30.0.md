## Конвертация прочих типов дампа в правила NDR

Записи URL/IP/CIDR/Regex/Phrase — легитимная часть базы фильтрации, но DNS-блокировка
работает только по доменам, поэтому они конвертируются по своим типам (ничего не теряется):

- **URL** → доменная часть (хост) попадает в DNS-список с категориями дампа, сам URL
  становится HTTP-правилом (`http.host` + `http.uri`, drop, SID 1 300 000+);
- **IP/CIDR** → IP-правила чанками по 500 адресов на SID (`drop ip`, SID 1 200 000+);
  приватные/служебные диапазоны (10/8, 127/8, CGNAT, link-local, multicast и др.)
  отбрасываются;
- **Regex** → pcre-правила на `http.uri.raw` (drop, SID 1 400 000+); шаблон валидируется
  компиляцией, слишком широкие (матчат «example.com», «microsoft.com» и «sberbank.ru»
  одновременно) отбрасываются;
- **Phrase** → правила по содержимому ответа `http.response_body` (drop, nocase,
  SID 1 500 000+) — кириллица матчится по UTF-8 байтам ответа;
- правила пишутся в `data/domains/ndr/dump-{ip,url,regex,phrase}.rules` с двуязычной
  шапкой (число правил/индикаторов, SID-блок, подсказка) и регистрируются как источники
  **«Дамп фильтрации: …» ВЫКЛЮЧЕННЫМИ** — правила загружаются в БД сразу (счётчик
  источника честный), в сборку попадают только после включения в «Правилах → Источниках»;
- экранирование значений: content — `\\` и `\"`, pcre — только `\/` и `\"` (синтаксис
  регулярного выражения `\.` `\d` не искажается); URL без пути получает `/`;
- дубликаты доменов дампа (один домен из разных resource-строк и из URL-ресурсов)
  дедуплицируются при импорте — `createMany` не нарушает unique `[sourceId, domain]`;
- статистика импорта по типам (URL/IP/CIDR/Regex/Phrase → сгенерированные правила,
  хосты URL) — в ответе API, журнале и зелёной/синей плашках вкладки «Источники»;
- подсказка диалога «Импорт базы» объясняет судьбу каждого типа.

## Сквозная проверка (тестовый дамп со всеми типами через POST /api/dns/import)

- домен + хост URL в DNS-списке с категориями дампа (`phish.example.com` [1,2],
  `urlbad.example.com` [2] — fromUrl);
- 4 выключенных источника «Дамп фильтрации: …» с загруженными правилами: 1 IP-правило
  (2 индикатора, приватный 10.0.0.5 отброшен), 2 HTTP-правила, 1 pcre, 1 response_body;
- `.rules`-файлы с шапками в `data/domains/ndr/`;
- повторная DNS-сборка включает импортированные домены, `GET /api/dns/export` их отдаёт;
- после чистки тестовых данных — повторная сборка и отдача работают штатно.
